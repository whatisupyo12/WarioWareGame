Quick, Timer's UP!
A quick collection of fast paced minigames including a platformer and clicker game

Game link: https://2002-2.itch.io/quick-timers-up

- Main Menu Screen for starting game and adjusting fullscreen settings
- Level intermission screens in between levels for when levels are completed/lost
- Level select scene where games can be played in order, and when one minigame is beat, is available to play by itself.
- Platformer minigame using arrow keys for side-to-side movement and space for jump
- Seesaw minigame, where weights randomly spawn on seesaw, and user has to drop more weights to balance
- Launcher minigame where user has to hit a moving target
- Clicker Minigame where user will need to click on all icons
- Celebratory finished screen

In the platformer game, the player needs to collect all the hearts before the timer ends, and can use A and D to move left and right or arrow keys, but spacebar is only jump button.
In the clicker game, the player needs to clock on all hearts before timer ends.
In the seesaw game, the player needs to select an option of the weight they want to drop, 1, 5, 10 kilogram, and drop by clicking.
The seesaw cannot touch the ground until the timer ends for the player to move on.
In the launcher game, the player can click and hold or hold spacebar to select a power, and aim the cannon by using mouse. The target needs to be hit before the timer ends.
The intermission screens show how many lives the player has remaining.

The level select scene also saves data, like when a level is beat, it should be able to be played by itself if you come back to the game later.
